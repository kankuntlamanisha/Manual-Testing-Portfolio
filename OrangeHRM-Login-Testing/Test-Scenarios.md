# OrangeHRM Login Testing – Test Scenarios

## Project Overview
Application: OrangeHRM  
Module: Login  
Testing Type: Manual Testing  

## Objective
To verify that the login functionality works correctly under different conditions.

## Test Scenarios

1. Verify login with valid credentials
2. Verify login with an invalid password
3. Verify login with invalid username
4. Verify login with an empty username
5. Verify login with an empty password
6. "Verify login with both username and password empty"
7. Verify password masking
8. Verify login button is visible 
9. Verify username field visibility
10. verify password field visibility
11. verify forgot password link is visibility
